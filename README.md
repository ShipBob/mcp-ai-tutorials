# ShipBob: MCP Tutorials

Hands-on, copy-paste tutorials for using Claude with ShipBob's MCP (Model Context Protocol) server. Each tutorial below is self-contained: connect once, then work through any topic in any order.

## Who this is for

Anyone running fulfillment with ShipBob who wants to use AI agents and assistants to access and manage it: orders, inventory, WRO, billing, and much more.

## What's needed

1. A ShipBob account
2. Claude Desktop, Claude Code, or ChatGPT with an active subscription

## Tutorials

| Topic | What's inside |
|---|---|
| [00_getting_started](00_getting_started/) | Connect Claude Desktop to ShipBob, then connect a second business |
| [01_inbound_and_wro](01_inbound_and_wro/) | Create a warehouse receiving order (WRO), by prompt or from a packing slip |
| [02_automated_reporting](02_automated_reporting/) | Get an automated daily inbound report, two different ways |
