# Automated Reporting

Get a daily inbound report without asking for it every time. Two different ways to do it: pick whichever fits how your team works:

1. [Claude Routines](01_claude_routines.md) (Claude runs the report on its own schedule, no Slack setup required)
2. [Claude Tag + Slack](02_claude_tag_slack_reports.md) (the report shows up in a Slack channel your team already watches)
